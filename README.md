# 🎬 MovieHunt

MovieHunt is a **React-based movie search web application** that allows users to quickly search and explore movies. The app fetches real-time movie data from an external API and displays movie posters, ratings, and details in a clean and responsive interface.

## 🚀 Live Demo

🔗 **Live Website:**
https://moviehuntakash.netlify.app/

## 📂 GitHub Repository

🔗 **Repository Link:**
https://github.com/AkashRajshekhar/MovieHunt-

## ✨ Features

* 🔍 Search for movies instantly
* 🎥 View movie posters and titles
* ⭐ Display movie ratings and release year
* ⚡ Fast and responsive UI
* 📱 Mobile-friendly design

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **Movie API**



## ⚙️ Installation & Setup

1. Clone the repository

```
git clone https://github.com/AkashRajshekhar/MovieHunt-
```

2. Navigate to the project folder

```
cd MovieHunt
```

3. Install dependencies

```
npm install
```

4. Run the development server

```
npm run dev
```
